# SmartLogix

Monorepo del sistema SmartLogix.

## Estructura

```
smartlogixs/
├── docs/                       # Documentación, diagramas, informes
├── frontend/                   # Aplicación frontend
└── backend/
    ├── bff/                    # Backend For Frontend
    └── microservicios/
        ├── apigateway/         # API Gateway
        ├── ms-envio/           # Microservicio de envíos
        ├── ms-inventario/      # Microservicio de inventario
        └── ms-pedido/          # Microservicio de pedidos
```
